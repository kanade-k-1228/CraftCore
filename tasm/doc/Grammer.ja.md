# 文法

## 定義

プログラムは定義 (def) の集合です。

|            | 記法                                              |
| ---------- | ------------------------------------------------- |
| 型         | `type Vec3 = {x : int, y : int, z : int};`        |
| 定数       | `const cst = 123;`                                |
| 静的変数   | `static x : int;`                                 |
| アセンブリ | `asm reset { jump(main); }`                       |
| 関数       | `fn add(a : int, b : int) -> int { return a+b; }` |

```
def =
 | type   = 'type' ident '=' type ';'
 | const  = 'const' ?('@' expr) ident '=' expr ';'
 | static = 'static' ?('@' expr) ident ':' type ';'
 | asm    = 'asm' ?('@' expr) ident '{' asm_stmt* '}'
 | func   = 'fn' ident '(' args ')' ?('->' type) block
```

`const` / `static` / `asm` は ident の前にオプションで `@ expr` でメモリアドレスを固定できます。`expr` は定数式である必要があります。

### 型定義

`type` 文で独自の型 (型エイリアスや構造体) を定義します。

```
type Vec3 = {x : int, y : int, z : int};
```

### 定数定義

`const` 文で定数を定義します。型は初期値から推論されます。

```
const cst = 123;
const msg = "Hello, World!\n";
```

`@` でアドレスを指定すると、データメモリ空間の固定アドレスに配置されます。指定しない場合は `const` セクション内に自動で割り付けられます。

```
const @ 0x3000 banner = "TASM";
```

### グローバル変数定義

`static` 文でグローバル (静的) 変数を定義します。型は明示します。

```
static x : int;
static @ 0x1000 serial_tx : int;
```

`@` でアドレスを指定すると、データメモリ空間の固定アドレスに配置されます。MMIO 領域の指定などに使います。指定しない場合は `static` セクション内に自動で割り付けられます。

### アセンブリ定義

アセンブリ命令列を直接記述するブロックです。プログラムメモリ空間に配置されます。

```
asm @ 0x0000 reset {
    jump(main);
}
```

`@` でアドレスを指定すると、プログラムメモリ空間の固定アドレスに配置されます。リセットベクタや割り込みベクタの指定に使います。指定しない場合は `code` セクションに自動で割り付けられます。

### 関数定義

```
fn add(a : int, b : int) -> int { return a+b; }
```

戻り値の型を省略した場合は `void` 扱いになります。関数本体は複文 (block) です。

## 型

|            | 記法                   |
| ---------- | ---------------------- |
| 整数型     | `int`                  |
| void 型    | `void`                 |
| ポインタ型 | `*int`                 |
| 配列型     | `[N]int`               |
| 構造体型   | `{m0 : int, m1 : int}` |
| 関数型     | `(arg : int) -> int`   |

```
type =
 | int    = 'int'
 | void   = 'void'
 | custom = ident
 | addr   = '*' type
 | arr    = '[' expr ']' type
 | struct = '{' (ident ':' type) % ',' '}'
 | func   = '(' (ident ':' type) % ',' ')' '->' type
```

### 整数型

`int` - 16 ビット整数を表します。符号付きか符号無しかは演算ごとにハードウェア命令で決まります (例: `lt`/`lts`, `sr`/`srs` など)。

### void 型

`void` - 値を持たないことを表します。主に値を返さない関数の戻り値型として使います。サイズは 0 です。

### ポインタ型

`*T` - 型 `T` の値へのポインタを表します。これは 16 ビットのメモリアドレスで、`T` 型のデータが格納された別のメモリ領域を参照します。

### 配列型

`[N]T` - 型 `T` の要素が `N` 個連続して割り当てられた静的配列です。配列のサイズはコンパイル時に既知でなければならず、動的なサイズ変更はサポートされません。`N` は定数式として評価されます。

### 構造体型

`{field1: T1, field2: T2}` - 複数の名前付きフィールドをまとめた合成データ型です。宣言された順に各メンバが連結された形でメモリ上に配置されます。

### 関数型

`(arg1: T1, arg2: T2) -> Ret` - 明示的な型を持つ固定数の引数を受け取り、`Ret` 型の値を返す関数を表します。関数型の変数は定義できません。代わりに関数ポインタ型 (`*(...) -> Ret`) を使います。

### 型のサイズ

tasm は Data = 16 bit / Address = 16 bit のシステム向けに設計されています。

型のサイズは次の計算規則に従い、コンパイル時に計算されます。

```
<int> = 1
<void> = 0
<*T> = 1
<[N]T> = N × <T>
<{f₁: T₁, f₂: T₂, ...}> = <T₁> + <T₂> + ...
<(args) -> Ret> = 0
```

これらの規則により、型のサイズは常にコンパイル時に計算可能です。`sizeof<T>` および `sizeof(expr)` 演算子は型または式の型が使用するメモリを 16bit 単位で返します。

### 参照演算子・アドレス演算子

`@a` で `a` をポインタとみなして、`a` の指す値を得ます (前置演算子・デリファレンス)。

`a : *int` → `@a : int`

`a@` で `a` のアドレスを得ます (後置演算子・アドレス取得)。

`a : int` → `a@ : *int`

`@` は前置で値方向 (`*T → T`)、後置でアドレス方向 (`T → *T`) と覚えると分かりやすいです。`*` は乗算および型表記 (`*T`) 専用になります。

### キャスト演算子

`expr as Type` で式の型を変換します。キャスト元とキャスト先の型サイズが一致している必要があります。

```
var p : *int = ...;
var n : int  = p as int;
```

サイズが不一致なキャストはコンパイルエラーになります。

### 整数型

16bit 整数。符号付きか無しかについては未定。ハードウェアの実装に委ねられます。命令レベルでは符号無し版 (`lt`/`lti`) と符号付き版 (`lts`/`ltsi`) などが用意されています。

### ポインタ型

ポインタ型は 16bit のアドレスです。アドレス空間が 16bit であることに由来します。

デリファレンス演算子を適用すると、ベース型になります。

`hoge : *int` → `@hoge : int`

アドレス演算子を適用すると、ポインタ型になります。

`hoge : int` → `hoge@ : *int`

### 配列型

配列はコンパイル時にベース型の N 個分のメモリを確保します。

添字演算子を適用すると、ベースの型になります。

`hoge : [N]int` → `hoge[0] : int`

多次元配列は、このように表されます。

`hoge : [N][M]int`

C 言語と異なり、配列とポインタの暗黙のキャストは行いません。

配列のアドレスが欲しい場合は、アドレス演算子を使います。

`hoge : [N]int` → `hoge@ : *[N]int`

配列の先頭の要素のアドレスは、このように取得します。

`hoge : [N]int` → `hoge[0]@ : *int`

これらのポインタの値は一致しますが、型は異なります。

### 構造体型

構造体のサイズはメンバの合計です。

メンバ演算子を適用すると、メンバの型になります。

`hoge : {a : int}` → `hoge.a : int`

### 関数型

関数型は関数の持つ型です。

関数呼び出し演算子を適用すると、返り値の型になります。

`hoge : (arg : Arg) -> Ret` → `hoge(arg) : Ret`

関数型の変数は定義できません。かわりに関数ポインタ型を使います。

`var hoge_p : *(arg : Arg) -> Ret = hoge@;` → `(hoge_p*)(arg) : Ret`

関数ポインタには関数のアドレスが入ってます。

## 文

関数定義には複文 (block satements) が続き、その中には文 (statement) が並びます。

```
stmt =
 | block    = ?( "'" ident ":" ) '{' stmt* '}'  # 複文
 | var      = 'var' ident ':' type ?('=' expr) ';' # ローカル変数定義
 | if       = 'if' '(' expr ')' stmt ?('else' stmt)
 | while    = 'while' '(' expr ')' stmt
 | break    = 'break' "'" ident ';'
 | continue = 'continue' "'" ident ';'
 | return   = 'return' ?( expr ) ';'
 | assign   = expr '=' expr ';'            # 代入文
 | expr     = expr ';'                     # 式文
```

### 式文

式を評価します。評価値は破棄されるため、実用上は副作用 (関数呼び出しなど) を実行するための文です。

### 代入文

代入文が変数の値を書き換える唯一の方法です。

左辺はアドレスとして評価できる必要があります (lvalue: 識別子・デリファレンス・添字・メンバアクセス)。右辺は値として評価されます。

`a : int = b : int`

という代入文は、実際には、

`a@ : *int <= b : int`

このような動作をしています。

### ローカル変数定義

`var` 文でローカル変数を定義します。型注釈は必須で、初期値は省略可能です。

```
var i : int = 0;
var v : Vec3;
```

ローカル変数は関数フレームのスタック上 (SP からの負オフセット、引数領域の直下) に確保されます。

### 制御文

`if` / `else` / `while` は C と同様に動作します。条件式は整数として評価され、0 で偽、それ以外で真とみなされます。

### ラベル付きブロック と break / continue

任意のブロック `{}` に `'label:` 形式のラベルを付けられます。`break 'label;` はラベル付きブロックの直後 (閉じ `}` の次) へジャンプし、`continue 'label;` はラベル付きブロックの先頭へジャンプします。

`break` / `continue` のラベルは省略できません。一致するラベルが (静的スコープで) 見えない場合はコンパイルエラーです。

```
'outer: {
  while (i < n) {
    'inner: {
      while (j < m) {
        if (x) break 'outer;     // 'outer の直後へ
        if (y) continue 'inner;  // 'inner の先頭へ
        j = j + 1;
      }
    }
    i = i + 1;
  }
}
```

`continue 'label;` はラベル付きブロックの先頭に戻るだけで、ブロック自体は自動でループしません。ループしたい場合は `while` を中に置きます (上の例の `'outer` がまさにそれです)。


## 式

### 演算子の優先順位

優先順位の低い順から:

```
expr  = or
or    = xor ('|' xor)*
xor   = and ('^' and)*
and   = eq ('&' eq)*
eq    = relat ('==' relat | '!=' relat)*
relat = shift ('<' shift | '<=' shift | '>' shift | '>=' shift)?
shift = add ('<<' add | '>>' add)?
add   = mul ('+' mul | '-' mul)*
mul   = unary ('*' unary | '/' unary | '%' unary)?
unary = postfix | '+' unary | '-' unary | '!' unary
```

### 単項演算子

```
unary =
 | post
 | pos    = '+' unary
 | neg    = '-' unary
 | not    = '!' unary
 | deref  = '@' unary
```

### 後置演算子

```
post =
 | prim
 | call   = post '(' expr % ',' ')'
 | index  = post '[' expr ']'
 | member = post '.' ident
 | ref    = post '@'
 | cast   = post 'as' type
```

## 値

```
prim =
 | number      # 数値リテラル
 | char        # 文字リテラル
 | string      # 文字列リテラル
 | ident       # 識別子
 | '(' expr ')' # 括弧付き式
 | '{' (ident ':' expr) % ',' '}' # 構造体リテラル
 | '[' expr % ',' ']' # 配列リテラル
 | 'sizeof' '<' type '>' # 型のサイズ
 | 'sizeof' '(' expr ')' # 式の型のサイズ
```

### 数値リテラル

- 10 進数: `123`, `1_000`
- 16 進数: `0x1234`, `0xff_ff`

### 文字リテラル

`'A'`, `'\n'`。

### 文字列リテラル

`"Hello, World!\n"`。`const` 定義の初期値として使い、データメモリ空間に文字単位で配置されます。

### エスケープシーケンス

文字リテラル・文字列リテラルで共通に `\n` `\t` `\r` `\\` `\'` `\"` `\0` をサポートします。

### `sizeof`

- `sizeof<T>` — 型 `T` のサイズ (16bit ワード単位)
- `sizeof(expr)` — 式 `expr` の型のサイズ

## アセンブリ

`asm` ブロック中では、ゼロ個以上のラベルに続けて 1 つの命令を書きます。

```
asm_stmt = (ident ':')* ident '(' expr % ',' ')' ';'
           ^^^^^^^^^^^^ labels  ^^^^^^^^^^^^^^^^^^^^^ instruction
```

ラベルは命令の前にいくつでも書けます。命令末尾のセミコロンは必須です。

### ラベル

`label:` の形式でラベルを定義します。`asm` ブロック内ローカルなラベルで、`jumpr` / `jumpifr` の相対ジャンプ先として使えます。

### 命令

`inst(arg1, arg2, ...);` の形式で命令を記述します。引数は式として評価され、レジスタ名・即値・グローバルシンボル・ローカルラベルのいずれかに解決されます。

サポートされる主な命令: `nop`, `mov`, `add`, `sub`, `and`, `or`, `xor`, `eq`, `neq`, `lt`, `lts`, `addi`, `subi`, `andi`, `ori`, `xori`, `eqi`, `neqi`, `lti`, `ltsi`, `not`, `loadi`, `load`, `store`, `sr`, `srs`, `srr`, `sl`, `slr`, `jump`, `jumpr`, `jumpif`, `jumpifr`, `call`, `ret`, `iret`。

`load(rd, base, imm)` / `store(rs, base, imm)` のように 3 引数で書くとレジスタ + 即値オフセットによるロード/ストア、2 引数で書くとゼロレジスタ基準の絶対アクセスになります。
